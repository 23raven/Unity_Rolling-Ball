# Unity Rolling Ball

**Unity Rolling Ball** is a simple 3D game made with Unity where the player controls a rolling ball and interacts with objects on the level.

## About
This project is based on the classic Unity beginner tutorial and adapted as a personal learning project, focusing on physics-based movement and basic level design.
